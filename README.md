# DeltaPulse 50x — Nifty-Style Crypto Momentum Screener (Android APK Ready)

## Included Files
- `www/index.html`, `www/styles.css`, `www/app.js`, `www/manifest.json` — Clean Nifty-Momentum style UI with Top 10 High-Volume Crypto, `Top 10 / BUY / HOLD / EXIT` tabs, live Delta Exchange chart, 50x `$10` levels (`+10%` net target), Option Chain & PCR verification, and Pre-Entry / Pre-Exit pop-up alerts.
- `.github/workflows/build-apk.yml` — GitHub Actions workflow that compiles the Android `.apk` directly without needing GitHub Pages.

## How to Build APK on GitHub
1. Extract this ZIP and upload all files (including `www/` and `.github/workflows/build-apk.yml`) to your GitHub repository.
2. Open the **Actions** tab on GitHub — the **Build DeltaPulse 50x Android APK** workflow will run automatically (~2 mins) and produce **`DeltaPulse-50x-Android-APK`** (`app-debug.apk`) under **Artifacts**.
